# Pomodoro Timer

A focus timer built around the pomodoro technique.

## Features

- 25 minute focus sessions with 5 minute and 15 minute breaks
- Progress ring and a countdown that stays accurate when the tab is inactive
- A long break offered after every fourth focus session
- Session dots, start/pause, reset and skip controls
- A short chime when the timer ends

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript. The chime is generated with the Web Audio API.
